# vi / Vim Cheat Sheet

Краткая шпаргалка для Betriebssysteme по присланным заметкам Rüdiger Weis.
Поток в источнике не указан. Полный текст: [vi-notes.txt](../source-extracts/vi-notes.txt).

## Главное: открыть → написать → сохранить → выйти

`vi dateiname` → `i` → ввод текста → `Esc` → `:wq` → `Enter`.
Если застрял: `Esc`, затем `:q!`, `Enter` — выйти без сохранения.

В **командном режиме** клавиши выполняют команды; в **режиме ввода** печатают текст.
Перед командами ниже нажми `Esc`. Команды с `:` и поиск `/` или `?` завершаются `Enter`.
Регистр имеет значение: `p` и `P` — разные команды.

## Ввод, изменение и выход

| Команда | Действие |
|---|---|
| `i` / `a` | Ввод перед / после курсора |
| `I` / `A` | Ввод перед первым непробельным символом / в конце строки |
| `o` / `O` | Новая строка ниже / выше, затем ввод |
| `Esc` | Вернуться в командный режим |
| `r` + символ | Заменить один символ |
| `cw` | Изменить слово, перейти к вводу |
| `c$` / `c)` | Изменить до конца строки / предложения |
| `:w` | Сохранить |
| `:q` | Выйти; несохранённые изменения блокируют выход |
| `:wq` / `ZZ` | Сохранить и выйти (`ZZ` записывает только изменённый файл) |
| `:q!` | Выйти, отбросив несохранённые изменения |
| `u` / `U` | Отменить последнее изменение / изменения текущей строки |
| `Ctrl-r` | Вернуть отменённое изменение (Vim) |
| `.` | Повторить последнее изменение |

## Перемещение

| Команда | Действие |
|---|---|
| `h` `j` `k` `l` | Влево, вниз, вверх, вправо |
| `w` / `b` | К началу следующего / предыдущего слова |
| `0` / `^` / `$` | Начало строки / первый непробельный символ / конец строки |
| `%` | К парной скобке |
| `{` / `}` | На абзац назад / вперёд |
| `(` / `)` | На предложение назад / вперёд |
| `Ctrl-f` / `Ctrl-b` | На экран вперёд / назад |
| `H` / `M` / `L` | Верхняя / средняя / нижняя строка экрана |
| `1G` / `gg` | Начало файла (`gg` — Vim) |
| `G` / `42G` | Конец файла / строка 42 |

## Удаление, копирование, вставка

| Команда | Действие |
|---|---|
| `x` | Удалить символ под курсором |
| `dd` / `dw` / `D` | Удалить строку / до начала следующего слова / до конца строки |
| `d}` / `d)` | Удалить до следующей границы абзаца / предложения |
| `yy` | Скопировать строку |
| `p` / `P` | Вставить после / перед курсором; строки — ниже / выше текущей |

Удалённый текст также можно вставить через `p` или `P`.
Составные команды: **число + оператор + перемещение**; `d` удаляет, `c` изменяет, `y` копирует.
Примеры: `3dd` — удалить 3 строки; `3yy` — скопировать 3 строки; `d3w` — удалить 3 слова.
Число работает и с перемещением: `3l`, `5b`, `4)`, `6}`.

## Поиск и замена

| Команда | Действие |
|---|---|
| `/text` / `?text` | Искать вперёд / назад |
| `n` / `N` | Повторить поиск в том же / обратном направлении |
| `#` | Искать слово под курсором назад (Vim) |
| `:s/alt/neu/` | Заменить первое совпадение в текущей строке |
| `:s/alt/neu/g` | Заменить все совпадения в текущей строке |
| `:%s/alt/neu/gc` | Заменить по всему файлу, подтверждая каждую замену |

`g` означает все совпадения **в каждой выбранной строке**, а не автоматически весь файл;
`%` выбирает весь файл, `c` запрашивает подтверждение.
В шаблоне поиска: `.` — любой символ кроме конца строки; `[abc]` — один из указанных символов;
`*` — 0 и более повторений предыдущего элемента; `\+` — 1 и более; `\=` — 0 или 1 (последние два — Vim).

## Выделение и дополнительные команды

**Vim:** `v` — посимвольное выделение, `V` — построчное; перемещением расширяй выделение,
затем `d` — удалить, `y` — скопировать, `c` — заменить. `Esc` отменяет выделение.
В выделении `p` / `P` заменяют выделенный текст содержимым регистра; для обычной вставки сначала выйди из выделения.

- `~` — переключить регистр символа.
- `>>` / `<<` — сдвинуть строку вправо / влево; `>` / `<` с перемещением или выделением — сдвинуть диапазон.
- `!` с перемещением — обработать текст shell-фильтром; `:!команда` — выполнить shell-команду.
- **Vim:** `:sp datei` — открыть файл в разделённом окне; `Ctrl-w Ctrl-w` — переключить окно; `:help` — помощь.

## Контекст

vi — экранный редактор, связанный со строчным редактором ex. Работает в терминале,
требует мало ресурсов и широко доступен; Vim — распространённая свободная реализация с расширениями.
Не все команды Vim поддерживаются классическим vi. В Emacs похожее управление дают Evil и Spacemacs.
