# vi: что реально нужно знать

Если цель — просто не застрять в терминале на Betriebssysteme, достаточно этого минимума:

```text
vi dateiname
```

Открыть файл.

```text
i
```

Начать ввод текста.

```text
Esc
```

Выйти из режима ввода обратно в командный режим.

```text
:w
```

Сохранить файл.

```text
:q
```

Выйти.

```text
:wq
```

Сохранить и выйти.

```text
:q!
```

Выйти без сохранения.

```text
dd
```

Удалить строку.

```text
yy
```

Скопировать строку.

```text
p
```

Вставить скопированное.

```text
/text
```

Искать `text` вперёд.

```text
u
```

Отменить последнее действие.

```text
Ctrl-r
```

Вернуть отменённое действие.

```text
gg
```

Перейти в начало файла.

```text
G
```

Перейти в конец файла.

Этого уже хватает для большинства базовых задач. Всё остальное ниже — полная шпаргалка Weis.

## Краткое введение в vi

`vi` — визуальный интерфейс для строчного редактора `ex`.

- https://de.wikipedia.org/wiki/Vi
- https://de.wikibooks.org/wiki/Learning_the_vi_editor

## Редактор доступен практически везде

- Свободное ПО, например `vim`
- Низкие требования к оборудованию
- Очень маленький размер
- Быстрый
- Гибкий

## Терминальный редактор

Можно использовать с буквенно-цифровой клавиатурой и клавишей `Esc`.

### Запуск vi

```text
vi dateiname
```

Открывает файл `dateiname`.

### Помощь

```text
:help
```

# Режимы vi

## Переход из командного режима в режим редактирования

| Команда | Действие |
|---|---|
| `a` | Вставлять после курсора |
| `i` | Вставлять перед курсором |
| `A` | Вставлять в конце строки |
| `I` | Вставлять в начале строки |
| `o` | Создать новую строку ниже |
| `O` | Создать новую строку выше |

## Переход из режима редактирования в командный режим

```text
Esc
```

# Change и Replace

## Replace

```text
r
```

Заменить один символ другим.

## Change

```text
cw
```

Изменить слово.

---

# Сохранение и выход

| Команда | Действие |
|---|---|
| `ZZ` | Сохранить и выйти |
| `:wq` | Сохранить файл и выйти |
| `:w` | Сохранить файл |
| `:q` | Выйти из vi |
| `:q!` | Выйти из vi без сохранения |

---

# Undo

```text
u
```

Отменить последнее изменение.

```text
U
```

Отменить все изменения в текущей строке.

```text
Ctrl-r
```

Redo — вернуть отменённое изменение.

```text
.
```

Повторить последнюю команду.

# Перемещение курсора по символам

| Команда | Действие |
|---|---|
| `h` | Влево |
| `j` | Вниз |
| `k` | Вверх |
| `l` | Вправо |

---

# Перемещение по словам, строкам и скобкам

| Команда | Действие |
|---|---|
| `w` | На слово вперёд |
| `b` | На слово назад |
| `^` | В начало строки |
| `$` | В конец строки |

## Парная скобка

```text
%
```

Перейти к соответствующей парной скобке.

---

# Перемещение по абзацам и экрану

| Команда | Действие |
|---|---|
| `{` | На абзац вверх |
| `}` | На абзац вниз |
| `Ctrl-f` | На экран вперёд |
| `Ctrl-b` | На экран назад |

---

# Начало и конец файла

| Команда | Действие |
|---|---|
| `gg` | В начало файла |
| `G` | В конец файла |

## Переход к строке

```text
42G
```

Перейти к строке 42.

# Замена

```text
:s/alt/neu
```

Заменить `alt` на `neu`.

## Опции

```text
/g
```

Применить замену глобально.

```text
/c
```

Спрашивать подтверждение перед заменой.

---

# Регулярные выражения

```text
.
```

Любой символ, кроме конца строки.

```text
[abc]
```

Один из символов:

- `a`
- `b`
- `c`

## Квантификаторы

```text
*
```

Любое количество повторений, включая 0.

```text
\+
```

Минимум одно повторение.

```text
\=
```

0 или 1 повторение.
