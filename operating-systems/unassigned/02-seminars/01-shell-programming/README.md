# Shell Programming: Exercise Sheet 1 Solutions

Решения — обычные текстовые файлы `.sh` для стандартной оболочки `sh`.
Поток не подтверждён, поэтому папка находится в `unassigned/02-seminars`.

## На MacBook

Открой Terminal и перейди в папку решений:

```sh
cd '/Users/damirahavaashova/Desktop/3 semester/operating-systems/unassigned/02-seminars/01-shell-programming'
vimtutor
vi 01-last-two.sh
```

В `vi`: `i` — ввод, `Esc` — командный режим, `:wq` + Enter — сохранить и выйти.
`vimtutor` нужно пройти самостоятельно. Листы 1 и 2 по заданию выполняются в `vi`.
Основная тема ДЗ — аргументы и управление потоком в shell; `vi` — редактор для работы с ними.

## Запуск

```sh
sh 01-last-two.sh one 'two words' three four
sh 02-even-arguments.sh one two
sh 02-even-arguments.sh one two three
sh 03-short-filenames.sh
sh 04-reverse-arguments.sh one 'two words' three
```

Третий скрипт проверяет файлы в **текущей директории запуска**, включая скрытые имена.
Каталоги исключены; символические ссылки на обычные файлы учитываются.
Четвёртый сохраняет исходные номера: `3: three`, `2: two words`, `1: one`.
Условие не уточняет направление нумерации; здесь номер соответствует позиции входного аргумента.
Ноль аргументов считается чётным числом; минимальное количество условием явно не задано.

`sh script.sh` не требует разрешения на исполнение. Не запускай через `zsh`: задание требует `sh`.

## Использованные средства

`while`, `for`, `if`, `case`, `shift`, `break`, `continue`, `exit`, `test` (`[`),
`printf`, `$#`, `$1`, `$2`, `$0`, арифметика `$((...))`, перенаправление `>&2`.
Это средства POSIX sh, однако без конспекта лекции нельзя подтвердить, что все они разрешены преподавателем.
